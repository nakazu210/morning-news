# 毎朝のニュース(LINE配信+音声)

毎朝6時ごろ、選んだ種類のニュースを集めて要約し、**LINEに届けます**。
LINEのリンクから約5分の読み上げ音声も聞けます(iPhoneのポッドキャストアプリにも登録可能)。**費用は0円**です。

## 届くニュースの種類
| 種類 | 主な内容 |
|---|---|
| 生成AI全般 | 新しいAIサービス、大手企業の動き、仕事での活用 |
| 住宅・不動産 | 住宅業界の動向、注文住宅、住宅ローン、省エネ・補助金などの制度 |
| 岡山県の自治体ニュース | 県や市町村の補助金・助成、移住・子育て支援、住宅政策、まちづくり |

**管理画面**(`https://ユーザー名.github.io/morning-news/admin.html`)で、種類ごとにオン・オフを切り替えられます。
新しい種類を増やしたいときは `config.json` に追加します。

## 仕組み
1. ニュースサイトのRSS・Googleニュース検索から、種類ごとに記事を集める
2. Gemini(無料枠)が読み上げ原稿とLINE用の要約を書く
3. VOICEVOXで音声にして、GitHub Pagesで公開
4. LINE公式アカウントから自分宛てに要約と音声リンクを送る

## ファイルの役割
| ファイル | 役割 |
|---|---|
| `config.json` | ニュースの種類と取得元(管理画面から書き換わる) |
| `generate.py` | ニュース収集・原稿作成・音声作成 |
| `build_feed.py` | 音声一覧ページ・ポッドキャスト用フィード・管理画面を作る |
| `notify_line.py` | LINEに送る |
| `admin.html` | 管理画面のもと |
| `.github/workflows/daily.yml` | 毎朝の自動実行の設定 |

## 必要な登録(GitHubの Settings → Secrets and variables → Actions)
| 名前 | 中身 |
|---|---|
| `GEMINI_API_KEY` | https://aistudio.google.com/apikey で作るキー |
| `LINE_CHANNEL_ACCESS_TOKEN` | LINE Developersの「チャネルアクセストークン(長期)」 |
| `LINE_USER_ID` | LINE Developersの「あなたのユーザーID」(Uから始まる) |

どれかが未登録でも止まりません(Geminiなし→見出しの読み上げ、LINEなし→送信だけ省略)。

## カスタマイズ
- **配信時刻**:`daily.yml` の `cron`(UTCで指定。日本時間 −9時間)
- **声**:`daily.yml` の Generate ステップに `VOICEVOX_SPEAKER: "3"`(ずんだもん)などを追加。
  変えたら `VOICEVOX_CREDIT` も合わせて変更
- **読む速さ**:`VOICEVOX_SPEED`(標準1.15)

## 無料枠について
- 公開リポジトリなので GitHub Actions は無料・無制限
- 音声は直近7日分だけ残し、古いものは自動削除
- LINEの無料メッセージは月200通。1日1通なので月30通程度

## 注意
- 公開リポジトリなので、URLを知っていれば誰でも音声ページを見られます(検索には載らない設定)。
  管理画面は誰でも開けますが、保存にはトークンが必要なので他人には変更できません
- 要約はAIが記事の見出しと概要から作るため、誤りが含まれることがあります。大事な情報は元記事で確認してください
- VOICEVOXの利用規約により、音声には「VOICEVOX:キャラ名」のクレジットを表記しています
